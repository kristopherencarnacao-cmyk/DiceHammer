# DiceHammer

Single-file D6 dice roller (`index.html`, no build step). Live at https://kristopherencarnacao-cmyk.github.io/DiceHammer/ via `.github/workflows/pages.yml`.

## Standing rule
Deploy every change to GitHub: after any change to the app, commit it and push to `main` (the Pages workflow redeploys automatically). If the claude.ai artifact "D6 Dice Tray" is also updated, keep `index.html` in sync with it.
