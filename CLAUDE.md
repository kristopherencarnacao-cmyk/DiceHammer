# PhosphorDice (formerly DiceHammer)

Single-file D6 dice roller (`index.html`, no build step). Live at https://kristopherencarnacao-cmyk.github.io/DiceHammer/ via `.github/workflows/pages.yml`.

## Visual design
Read `DESIGN.md` before any visual change: it is the full style spec (tokens, themes, components, motion, layout). Keep it updated when the look changes.

## Standing rule
Deploy every change to GitHub: after any change to the app, commit it and push to `main` (the Pages workflow redeploys automatically). If the claude.ai artifact "PhosphorDice" (formerly "DiceHammer" / "D6 Dice Tray") is also updated, keep `index.html` in sync with it.
After every push, give Kristopher the live web link in the reply: https://kristopherencarnacao-cmyk.github.io/DiceHammer/
